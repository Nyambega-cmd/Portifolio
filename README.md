# Kevin Mongare Portfolio (GitHub Pages + PWA)

Complete and ready to publish. No build step. Nothing needs replacing.

## Publish in 3 clicks
1. Create a GitHub repository and upload everything in this folder (**Add file → Upload files**).
2. Open **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and `/ (root)`, then **Save**. The site goes live in a minute or two.

## Contact details
`js/config.js` already holds your email, phone and WhatsApp. Add `github` or `linkedin` links there when you want them shown, or clear any value to hide it.

## Swap in your own material later
- Replace the illustrated project images in `assets/images/` with real photos (keep the filenames, or edit the paths in `index.html`).
- Replace `assets/docs/Kevin_Mongare_CV.pdf` and `CBC_CBET_Samples.pdf` with your own PDFs of the same name. To show your TSC certificate, add the PDF and turn its "Request a copy" button into Preview/Download buttons by copying the pattern from the CV card.
- After any change, bump `knm-v3` to `knm-v4` in `sw.js` so returning visitors get the update.

## Install on Android
Open the site in Chrome and tap **Install App** in the header, or use the browser menu and choose **Install app / Add to Home Screen**.
